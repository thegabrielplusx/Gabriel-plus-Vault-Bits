 Gabriel plus Vault Bits es una aplicación de seguridad personal diseñada para convertir tu sistema retro clásica en un
dispositivo de almacenamiento blindado. Olvídate de anotar tus contraseñas en papeles que se pierden o de usar aplicaciones modernas que requieren conexión a internet. Ahora puedes llevar tus códigos bancarios, llaves de juegos, mensajes secretos o cualquier información confidencial directamente en tu bolsillo, protegidos en un sistema retro clásico.

✨ Características Principales

💾 Memoria Permanente (SRAM): Tus datos persisten aunque apagues la consola.
🎨 Interfaz Retro**: Diseño visual inspirado en los juegos clásicos de Retro.
🛡️ Seguridad por Ofuscación: Sistema de encriptación XOR con firma digital.
👁️ Modo Privacidad: Oculta/muestra contraseñas con un solo botón.
⚠️ Borrado Seguro: Función de pánico para eliminar todos los datos instantáneamente.
🎮 Controles Intuitivos: Manejo sencillo similar a un videojuego antiguo.

🎮 Controles

➡️ Derecha| Mover cursor a la siguiente posición 
⬅️ Izquierda| Mover cursor a la posición anterior 
⬆️ Arriba| Incrementar carácter 
⬇️ Abajo| Decrementar carácter 
| **L**| Cambiar al slot anterior 
| **R**| Cambiar al siguiente slot 
| **SELECT**| Mostrar/Ocultar contraseña (modo privacidad) 
| **START**| 💾 Guardar permanentemente en SRAM
