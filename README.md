 Gabriel plus Vault Bits es una aplicación de seguridad personal diseñada para convertir tu sistema retro clásica en un
 dispositivo de almacenamiento blindado. Olvida anotar tus contraseñas en papeles que se pierden; ahora puedes llevar tus códigos bancarios,
 llaves de juegos o mensajes secretos directamente en tu bolsillo, protegidos en un sistema retro. todo programado en C

(Controles)
​El manejo es muy sencillo, similar a un videojuego antiguo:
​Cruceta (Derecha / Izquierda): Te mueves entre las letras de tu contraseña actual.
​Cruceta (Arriba / Abajo): Cambias la letra o número seleccionado (A, B, C... 1, 2, 3...).
​Botones L y R (Gatillos): Cambias de "Slot" o casilla. Tienes 10 casillas disponibles para guardar 10 claves distintas.

​Botón SELECT: Funciona como un "interruptor de privacidad". Si lo pulsas, la contraseña se convierte en puntitos negros; si lo pulsas otra vez, se muestra el texto.
​Botón START: ¡Muy importante! Al pulsarlo, guardas permanentemente lo que hayas escrito en la memoria.
​L + R al mismo tiempo: Es el botón de "pánico" o borrado total. Si mantienes ambos, se borrarán todas las claves de la bóveda para siempre.

Memoria Permanente: Aunque apagues la consola, gracias a la función de guardado (SRAM), tus claves estarán ahí la próxima vez que la enciendas.
Seguridad Invisible: El programa utiliza una "firma secreta" y un sistema de "mezclado" (XOR) para que, si alguien intentara leer los datos directamente de la memoria, solo vea basura sin sentido.
